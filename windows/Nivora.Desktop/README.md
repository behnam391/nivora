# Nivora Desktop

کلاینت سبک ویندوز Nivora با رابط WebView2 و موتور TUN. نسخه `1.2.0` شناسه دستگاه و نشست رمزنگاری‌شده کاربر را در پروفایل ویندوز نگه می‌دارد.

## ویژگی‌ها

- ورود ماندگار مشتری و دریافت اشتراک‌های فعال
- اتصال VLESS شامل Reality/TCP، gRPC و WebSocket
- رابط فشرده سه‌بخشی برای اتصال، اشتراک‌ها و حساب
- دسترسی مستقیم به کیف پول و پشتیبانی وب
- عدم دنبال‌کردن Redirect هنگام دریافت اشتراک برای جلوگیری از نشت هدرهای حساب
- پوشش کل سیستم، برنامه‌های بدون پشتیبانی Proxy و ترافیک UDP با TUN
- ورود ماندگار با Windows DPAPI، کوچک‌شدن در System Tray و آیکن استاندارد
- نصب‌کننده استاندارد، میانبر Start و Desktop و حذف تمیز برنامه

برای ساخت Route سراسری، برنامه هنگام اجرا دسترسی Administrator درخواست می‌کند. اگر موتور TUN همراه بسته نباشد، حالت پراکسی قدیمی فقط به‌عنوان پشتیبان فعال می‌شود.

## ساخت

به `.NET Framework 4.x`، فایل‌های `Microsoft.Web.WebView2` و هسته `xray.exe` نیاز است. فایل اجرایی باید کنار DLLهای WebView2، پوشه `ui` و پوشه `core` منتشر شود.
