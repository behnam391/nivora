# Nivora Desktop

کلاینت سبک ویندوز Nivora با رابط WebView2 و هسته Xray. نسخه `1.1.0` شناسه پایدار و تصادفی دستگاه را در `%LocalAppData%\Nivora\device.id` نگه می‌دارد و نشست و شناسه دستگاه را فقط برای دامنه رسمی Nivora ارسال می‌کند.

## ویژگی‌ها

- ورود ماندگار مشتری و دریافت اشتراک‌های فعال
- اتصال VLESS شامل Reality/TCP، gRPC و WebSocket
- رابط فشرده سه‌بخشی برای اتصال، اشتراک‌ها و حساب
- دسترسی مستقیم به کیف پول و پشتیبانی وب
- عدم دنبال‌کردن Redirect هنگام دریافت اشتراک برای جلوگیری از نشت هدرهای حساب
- ذخیره و بازیابی تنظیم پراکسی قبلی ویندوز هنگام اتصال و قطع

این نسخه از پراکسی سیستم Windows استفاده می‌کند و TUN کامل نیست؛ بنابراین برنامه‌ای که پراکسی سیستم را نادیده بگیرد یا فقط UDP بخواهد، در این نسخه پوشش داده نمی‌شود.

## ساخت

به `.NET Framework 4.x`، فایل‌های `Microsoft.Web.WebView2` و هسته `xray.exe` نیاز است. فایل اجرایی باید کنار DLLهای WebView2، پوشه `ui` و پوشه `core` منتشر شود.
