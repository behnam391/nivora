# WireGuard و OpenVPN — مرحله آزمایشی

این مرحله مستقل از فروش نیوورا است؛ به معنی پشتیبانی داخل اپ نیوورا یا سهمیه مشترک نیست.

## وضعیت ۲۰۲۶-۰۹-۰۹

- فنلاند: WireGuard روی UDP/51820 و OpenVPN روی TCP/1194.
- Xray، Hysteria و وب تغییر نکردند.
- حساب pilot-iphone هفت روز اعتبار دارد؛ فایل‌ها خصوصی و خارج از مخزن نگهداری می‌شوند.
- فایل conf برای WireGuard و ovpn برای OpenVPN Connect است.
- IPv4 تونل می‌شود؛ IPv6 مسدود می‌شود، نه اینکه پشتیبانی کامل داشته باشد.
- تعلیق و انقضا با بررسی ۳۰ثانیه‌ای اعمال می‌شود؛ OpenVPN در شروع اتصال نیز اعتبار را بررسی می‌کند.
- کلید اختصاصی و tls-crypt، بررسی نام و نقش گواهی سرور، منع دسترسی تونل به شبکه‌های خصوصی و سرویس‌های خود میزبان فعال است.

## نصب روی سرور جدید

سه فایل ops/install-classic-vpn.sh، ops/nivora-classic-vpn.mjs و ops/classic-vpn-profiles.mjs کنار هم قرار گیرند. Ubuntu، Node.js، دسترسی root و TUN لازم است.

```sh
bash install-classic-vpn.sh PUBLIC_IPV4
nivora-classic add test-iphone 7
nivora-classic export test-iphone
nivora-classic suspend test-iphone
nivora-classic resume test-iphone
nivora-classic renew test-iphone 7
nivora-classic status
```

نصاب اگر نصب قبلی یا پورت/زیرشبکه متداخل ببیند متوقف می‌شود؛ کلیدها را بازنویسی نمی‌کند. پورت‌های انتخابی در فایروال ارائه‌دهنده نیز باید مجاز باشند.

## قبل از فروش ضروری است

- اتصال امن ابزار نود به پنل و سطح دسترسی مدیر/نماینده/مشتری.
- اتصال ایجاد، تمدید و تعلیق به خرید با قابلیت جبران شکست ناقص.
- حسابداری پایدار حجم مشترک با Xray، قطع پس از اتمام سهمیه و بازیابی پس از ریبوت.
- QR و دانلود احرازهویت‌شده، بدون قراردادن کلیدها در لینک عمومی.
- تمدید خودکار گواهی‌ها (گواهی فعلی یک‌ساله است؛ تمدید اعتبار حساب گواهی را تمدید نمی‌کند).
- تست اینترنت اپراتورها و آیفون؛ اتصال از داخل سرور کیفیت اینترنت مشتری را اثبات نمی‌کند.
- پاک‌سازی یا تعویض کلید حساب آزمایشی قبل از هر استفاده تجاری.

فعلاً ابزار حذف دائمی ندارد؛ برای لغو دسترسی از suspend استفاده شود. فایل‌های کلید و exports هرگز commit یا عمومی نشوند. فقط گرفتن پشتیبان رمزگذاری‌شده از /etc/nivora-classic و /etc/wireguard مجاز است.

## توقف آزمایش بدون دست‌زدن به مسیرهای قبلی

```sh
systemctl disable --now nivora-classic-sync.timer
systemctl disable --now wg-quick@nvwg0 openvpn-server@nivora-classic
```

این دستور داده و کلید را پاک نمی‌کند. قواعد اختصاصی فایروال باقی می‌مانند اما سرویس شنونده‌ای روی آن دو پورت وجود نخواهد داشت.
