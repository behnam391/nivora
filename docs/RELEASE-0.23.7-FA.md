# 0.23.7 — Orbit

بازطراحی بومی صفحه اتصال با زمینه زغالی و رنگ یاسی؛ بدون وابستگی جدید.

- حلقه اتصال مرکزی: خطوط شعاعی، دو مدار متحرک در زمان اتصال/قطع، حلقه تکمیل‌شونده پس از اتصال واقعی.
- حالت آماده، خطا و متصل بدون انیمیشن بی‌پایان؛ انیمیشن اتصال از تنظیم مدت انیمیشن Compose پیروی می‌کند.
- لغو/قطع همان فرمان قبلی است. حالت اتصال فقط از سرویس VPN خوانده می‌شود؛ هیچ پیشرفت درصدی ساختگی نمایش داده نمی‌شود.
- نوار دسترسی یکپارچه، مقصد و پینگ واقعی، کارت اشتراک با حاشیه ملایم، حذف زمینه‌های دایره‌ای بزرگ و نمای ورود قبلی.
- رنگ‌های مشترک صفحات، مشتری و همکار را یکدست می‌کنند؛ منطق فروش و شبکه تغییر نکرده است.
- آیکن نصب‌شده لانچر و امضای برنامه حفظ شده‌اند. انتشار عمومی مستقل از ساخت و نصب آزمایشی است.

بررسی لازم: ساخت release هر دو flavor، تست‌های واحد و مشاهده چیدمان روی گوشی. تست UI به معنی تأیید سرعت یا پایداری اینترنت نیست.
