# راهنمای عملیات و بازیابی Nivora

این راهنما برای زمانی است که IP، دامنه، پنل ثنایی یا خود سرور تغییر می‌کند. اطلاعات محرمانه مانند توکن، کلید خصوصی و فایل `.env` نباید در GitHub قرار بگیرند.

## کارهای روزمره از پنل مدیریت

در «مدیریت ← مرکز زیرساخت» هر سرور یک کارت مستقل دارد:

1. «ویرایش آدرس‌ها» را باز کنید.
2. آدرس پنل/API، آدرس پایه اشتراک و شناسه‌های ورودی Reality، CDN و Hysteria را اصلاح کنید.
3. اگر توکن عوض نشده، کادر توکن را خالی بگذارید؛ برای توکن جدید همان‌جا مقدار تازه را وارد کنید.
4. ذخیره کنید و «تست سلامت» را بزنید. نتیجه آنلاین/آفلاین و زمان پاسخ نمایش داده می‌شود.
5. در «لوکیشن‌ها» بررسی کنید لوکیشن به سرور درست و پلن‌های درست متصل باشد.

تغییر اطلاعات سرور، لوکیشن یا پلن سوابق مشتریان را حذف نمی‌کند. پیش از تغییر گسترده یک بکاپ بگیرید.

## تعویض سریع IP یک لوکیشن

1. IP جدید را روی خود سرور فعال و SSH، پنل، Xray و فایروال را بررسی کنید.
2. رکورد DNS مستقیم همان لوکیشن را به IP جدید تغییر دهید و آن را برای Reality، Hysteria و OpenVPN روی حالت **DNS only** نگه دارید.
3. مسیرهای وب پنل و اشتراک را با Cloudflare Tunnel یا reverse proxy معتبر به مقصد جدید ببرید.
4. در مرکز زیرساخت Nivora، آدرس پنل و اشتراک را اصلاح و تست سلامت را اجرا کنید.
5. اگر گواهی بر مبنای IP بوده، برای IP جدید گواهی معتبر نصب کنید. در حالت دامنه، گواهی دامنه را نگه دارید.
6. یک اشتراک آزمایشی تازه بسازید و اتصال واقعی روی همراه اول، ایرانسل و اینترنت ثابت را آزمایش کنید.

ساب‌دامین DNS-only جایگزین‌کردن IP را سریع می‌کند، اما IP را از یک بررسی فنی DNS پنهان نمی‌کند. Cloudflare Tunnel فقط برای HTTP/HTTPS پنل و لینک اشتراک مناسب است؛ Reality، Hysteria، WireGuard و OpenVPN خام از Tunnel عبور نمی‌کنند.

## بررسی فوری سلامت

روی سرور مرکزی اجرا کنید:

```bash
sudo nivora doctor
```

این دستور سرویس اصلی، API محلی، تایمر بکاپ، سرورها، توکن‌های ثبت‌شده، اتصال لوکیشن‌ها به پلن و تازه‌ترین بکاپ را بررسی می‌کند. برای گزارش سرویس:

```bash
sudo nivora status
sudo nivora logs
```

## بکاپ استاندارد

بکاپ دیتابیس:

```bash
sudo nivora backup
```

بسته کامل بازیابی شامل دیتابیس Nivora، تنظیمات محرمانه، رسیدها و در صورت نصب محلی دیتابیس 3x-ui:

```bash
sudo nivora recovery-export
```

فایل `nivora-recovery-*.tar.gz` را بلافاصله از سرور خارج و در محل رمزگذاری‌شده نگه دارید. این فایل نباید در مخزن عمومی، کانال یا فضای دانلود مشتری قرار گیرد.

## نصب کامل روی سرور جدید

نصب تازه از مخزن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/behnam391/nivora/main/install.sh)
```

بازیابی از بسته‌ای که قبلاً روی سرور جدید کپی شده است:

```bash
export NIVORA_RECOVERY_FILE=/root/nivora-recovery-YYYYMMDDTHHMMSSZ.tar.gz
bash <(curl -fsSL https://raw.githubusercontent.com/behnam391/nivora/main/install.sh)
unset NIVORA_RECOVERY_FILE
```

بعد از نصب، DNS/Cloudflare را به سرور جدید ببرید، وارد مدیریت شوید، تک‌تک کارت‌های سرور را تست کنید و سپس فروش را باز کنید.

## نصب OpenVPN فروش‌پذیر روی لوکیشن جدید

فایل‌های پوشه `ops/` برای نصب تکرارپذیر نگهداری می‌شوند. روی سرور مقصد، نام دامنه DNS-only همان لوکیشن را بدهید:

```bash
sudo bash ops/install-classic-vpn.sh tr.example.com
sudo bash ops/enable-openvpn-sales.sh
```

ایجنت فروش نباید بدون محدودیت روی اینترنت باز باشد. برای سرور راه‌دور، TLS و فایروال محدود به IP سرور مرکزی الزامی است:

```bash
sudo bash ops/enable-openvpn-remote-agent.sh CONTROL_SERVER_IPV4
```

سپس در مرکز زیرساخت یک سرور از نوع OpenVPN بسازید، آدرس HTTPS ایجنت و توکن `/etc/nivora-classic/sales-token` را ثبت و تست سلامت را اجرا کنید. توکن را در پیام‌رسان یا GitHub نفرستید.

## چک‌لیست قبل از فروش

- هر کارت سرور در مرکز زیرساخت «آنلاین» باشد.
- برای هر کشور یک خرید آزمایشی و یک تمدید آزمایشی موفق باشد.
- اتصال واقعی فقط با پینگ سنجیده نشود؛ بازشدن ویدئو، شبکه اجتماعی، تماس صوتی و پایداری حداقل ۱۵ دقیقه آزمایش شود.
- Reality/Hysteria مسیر اصلی و OpenVPN مسیر سازگار/اضطراری باشد.
- آخرین بسته بازیابی خارج از سرور نگهداری شود.
- لینک پنل، توکن و IP خام در کانال عمومی یا فایل APK قرار نگیرد.

## چیزی که پنل عمداً انجام نمی‌دهد

پنل وب فرمان root دلخواه اجرا نمی‌کند و کلید SSH نگه نمی‌دارد. نصب سیستم‌عامل، تغییر شبکه اصلی و بازیابی کامل با دستورهای محدود بالا انجام می‌شود. این مرز امنیتی مانع تبدیل‌شدن حساب مدیریت وب به دسترسی کامل تمام سرورها می‌شود.
