# 0.23.8 — تب‌های پایین صفحه

- نوار ثابت شش‌تب مشتری: اتصال، خرید، کیف پول، پشتیبانی، حساب، تلگرام.
- حذف ردیف دکمه‌های وسط صفحه اتصال.
- حذف نوار کانال و ربات از صفحات مشتری واردشده؛ انتقال به صفحه مستقل تلگرام با آیکن هواپیمای کاغذی.
- زنگ بالای صفحه اتصال همچنان اعلان‌ها را باز می‌کند.
- ابعاد حلقه از 192 به 168dp کاهش یافته تا فضای اشتراک بیشتر باشد.
- منطق شبکه و فروش بدون تغییر؛ داده و نشست کاربر هنگام نصب به‌روزرسانی حفظ می‌شود.
- بخش همکار هنوز ناوبری مستقل خود را دارد؛ این تغییر نوار تب مربوط به مشتری است.
