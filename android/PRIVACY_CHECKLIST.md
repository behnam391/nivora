# چک‌لیست حریم خصوصی و انتشار

- متن رضایت مستقل VpnService پیش از اولین اتصال
- سیاست حریم خصوصی روی دامنه رسمی و داخل اپ
- عدم ثبت لینک اشتراک، UUID، کلید Reality و محتوای ترافیک در لاگ
- اعلام دقیق شماره موبایل، داده‌های تشخیصی و شناسه دستگاه در Data Safety
- رمزگذاری HTTPS برای API و تونل رمزگذاری‌شده تا endpoint
- ویدیوی حداکثر ۹۰ ثانیه برای جریان اتصال و رضایت Play Console
- امکان خروج از حساب و حذف داده محلی
- صفحه مجوزهای MIT، MPL-2.0 و سایر اجزای شخص ثالث
- کلید امضای release خارج از ریپازیتوری و همراه بکاپ آفلاین
