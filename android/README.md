# Nivora Android

اپ اندروید یک پروژه جدا از پنل سرور خواهد بود تا رابط کاربری و منطق تجاری اختصاصی بماند. پیشنهاد فنی:

- Kotlin + Jetpack Compose
- معماری Clean/MVVM
- ارتباط با API سرور Nivora برای ورود، کیف پول، خرید، تمدید، تیکت و اعلان
- Android `VpnService` برای تونل دستگاه
- هسته اتصال `XTLS/libXray` به‌جای فورک کامل v2rayNG
- ذخیره توکن در Android Keystore و EncryptedSharedPreferences
- نگهداری کانفیگ رمزگشایی‌شده فقط در حافظه تا حد امکان
- پشتیبانی اولیه از VLESS + Reality + Vision و Subscription URL

`libXray` پوشش Android و API اجرای Xray را فراهم می‌کند و مجوز خودش MIT است؛ Xray-core تحت MPL-2.0 باقی می‌ماند. فایل‌های مجوز و اعلان‌های شخص ثالث باید داخل اپ قرار بگیرند.

## نسخه اول اپ

1. ورود/ثبت‌نام با شماره و رمز
2. صفحه اصلی با وضعیت اتصال، پینگ و لوکیشن
3. دریافت خودکار اشتراک‌های فعال از حساب
4. اتصال/قطع با یک دکمه
5. خرید و تمدید از کیف پول
6. شارژ با رسید
7. اعلان پاسخ پشتیبانی و وضعیت پرداخت
8. انتخاب خودکار سریع‌ترین کانفیگ
9. QR و واردکردن لینک برای کاربران قدیمی
10. به‌روزرسانی کنترل‌شده APK از سرور خصوصی یا انتشار Google Play

## تصمیم انتشار

برای شروع، APK امضاشده از دامنه خودمان منتشر می‌شود تا وابسته به محدودیت پرداخت و دسترسی Google Play نباشیم. هم‌زمان اپ مطابق سیاست‌های Play ساخته می‌شود: VPN باید قابلیت اصلی باشد، استفاده از VpnService در صفحه فروشگاه توضیح داده شود، داده‌ها رمزگذاری شوند و در صورت دسترسی به داده حساس، رضایت برجسته داخل اپ نمایش داده شود.

فورک مستقیم v2rayNG برای نسخه نهایی توصیه نمی‌شود چون کل پروژه GPL-3.0 است. می‌توان از آن فقط برای مطالعه رفتار و تست سازگاری استفاده کرد؛ محصول اختصاصی روی libXray ساخته می‌شود.
